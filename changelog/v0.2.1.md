# Common UI and plugin packaging fixes

## Changes

- Migrated the app shell to the shared Common UI architecture, including the shared error boundary, theme provider, toast provider, and window frame.
- Added Tauri adapters for theme preferences, window controls, platform detection, and UI error reporting.
- Updated frontend and native dependencies, including the `bgutil-ytdlp-pot-provider` submodule.

## Fixes

- Fixed `bgutil` POT provider packaging so generated resources must contain the HTTP plugin and reject stale CLI-based plugins.
- Fixed runtime plugin discovery to ignore incomplete or mixed `bgutil` plugin directories instead of passing them to `yt-dlp`.

## Install

- Windows and macOS users can download Quiver from the latest GitHub release.
- macOS users may need to remove the quarantine attribute because the `.dmg` is not signed or notarized.
- macOS users need Homebrew `ffmpeg`: `brew install ffmpeg`.
- Linux users can download the `.deb`, `.rpm`, or AppImage package from the latest GitHub release.

## Notes

- Windows release builds are intended to work without a separate `Python`, `yt-dlp`, `Deno`, POT provider, or `FFmpeg` install.
- Linux release builds bundle `yt-dlp`, `Deno`, the POT provider, and `YTSubConverter`. AppImages also bundle `ffmpeg` and `ffprobe`; distribution packages install `ffmpeg` as a system dependency.
- macOS release builds bundle `yt-dlp`, `Deno`, the POT provider, and `YTSubConverter`, but still require Homebrew `ffmpeg` and `ffprobe`.

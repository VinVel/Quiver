# Many quality of life changes

# Additions

- Added AppImage builds for Linux, with bundled `ffmpeg` and `ffprobe` support.
- Added package repositories for Debian/Ubuntu/Linux Mint and Fedora/Nobara/Ultramarine Linux, including stable and prerelease channels.
- Added Chrome impersonation to YouTube presets to improve compatibility with YouTube downloads.
- Added native Windows ARM64 build support.

# Changes

- Bundled `yt-dlp` as a standalone sidecar on Windows, macOS, and Linux, removing the runtime dependency on Python or a separately installed `yt-dlp`.
- Replaced the Rust POT provider with the upstream `bgutil-ytdlp-pot-provider` and updated the bundled sidecars and application dependencies.
- Improved video output handling: video presets now consistently remux to MKV, convert embedded thumbnails to PNG, and preserve standard downloaded subtitle formats instead of converting them automatically.
- Improved the Advanced Subtitle Pipeline so existing subtitles, metadata, chapters, attachments, and cover art are preserved when converted subtitles are attached.
- Limited the built-in auto-updater to Windows and macOS; Linux updates are delivered through the package repositories.
- Moved the frontend UI components and theme system into the shared component submodule.
- Migrated frontend development and CI from Bun to pnpm and standardized builds on Node.js 24 and .NET 10.
- Refactored the sidecar build system and split platform-specific Tauri configuration for easier maintenance.

## Fixes

- Fixed startup crashes on Linux systems using NVIDIA GPUs.
- Fixed broken Windows ARM64 builds.
- Fixed AppImage creation and signing in the release workflow.
- Fixed thumbnail loss during Advanced Subtitle Pipeline remuxing.

## Install

- Windows and macOS users can download Quiver from the latest GitHub release.
- macOS users may need to remove the quarantine attribute because the `.dmg` is not signed or notarized.
- macOS users need Homebrew `ffmpeg`: `brew install ffmpeg`.
- Linux users can install Quiver from the new Debian/Ubuntu or Fedora package repository, or use a package from the latest GitHub release.

## Notes

- Windows release builds are intended to work without a separate `Python`, `yt-dlp`, `Deno`, POT provider, or `FFmpeg` install.
- Linux release builds bundle `yt-dlp`, `Deno`, the POT provider, and `YTSubConverter`. AppImages also bundle `ffmpeg` and `ffprobe`; distribution packages install `ffmpeg` as a system dependency.
- macOS release builds bundle `yt-dlp`, `Deno`, the POT provider, and `YTSubConverter`, but still require Homebrew `ffmpeg` and `ffprobe`.

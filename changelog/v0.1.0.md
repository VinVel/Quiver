# First Release!

This is the first release of my dead simple YT-DLP GUI. Boot it up, put in a link, hit Download and that's it. No manual configuring.

## Features

- Added the core Quiver download flow: paste a URL, choose a preset, prepare the generated `yt-dlp` command, then run it.
- Added eight built-in presets covering YouTube/general downloads, audio/video, and with/without cookies.
- Added command preview so the generated `yt-dlp` arguments stay visible before execution.
- Added live command output for the current download.
- Added configurable save directory and cookies file inputs, including native file/folder pickers.
- Added persistent app settings for save directory, cookies path, theme mode, and theme preset.
- Added bundled `yt-dlp` support for release builds, with `QUIVER_YT_DLP_BINARY` still available for local development overrides.
- Added bundled YouTube POT provider support through a local `bgutil` server for YouTube presets.
- Added optional Advanced Subtitle Pipeline for YouTube video downloads, converting YouTube `srv3` subtitles into visual `.ass` subtitles and remuxing them into the final file.
- Added light/dark mode, color theme presets, and an in-app third-party license viewer.

## Install

- Windows and macOS users can download Quiver from the latest GitHub release.
- macOS users may need to remove the quarantine attribute because the `.dmg` is not signed or notarized.
- macOS users need Homebrew `ffmpeg` for the Advanced Subtitle Pipeline: `brew install ffmpeg`.
- Linux users can install the `.deb` or `.rpm` package from the release, or download the AppImage instead.

## Notes

- Regular Windows and Linux release builds are intended to work without a separate `Python`, `yt-dlp`, `Deno`, POT provider, or `FFmpeg` install.
